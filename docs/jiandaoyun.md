# 简道云安装配置

应用、表单、字段和密钥均由使用者自行创建并保存在本地。不需要修改任何 Python 常量。

## 召回数据表

| 逻辑字段（配置键） | 推荐控件 |
|---|---|
| 日期 | 日期时间 |
| 公司 | 单行文本 |
| 车型 | 单行/多行文本 |
| 数量 | 数字 |
| 分类 | 单行文本 |
| 原因 | 多行文本 |
| 来源URL | 单行文本 |
| 备注 | 多行文本 |

配置项 `record_fields` 把这些逻辑名称映射到你自己的控件 ID。项目不依赖序号列，稳定去重键为“来源 URL + 日期 + 公司 + 数量”。

## 运行日志表

| 逻辑字段（配置键） | 推荐控件 |
|---|---|
| 运行时间 | 日期时间 |
| 本次新增召回 | 数字 |
| 本次推送简道云 | 数字 |
| 判定结论 | 多行文本 |
| 逐条明细 | 多行文本 |
| 子代理交叉比对 | 多行文本 |
| 推送 data_id | 多行文本 |

新增公告数写在结论里；“本次新增召回”指符合条件的增量行数，不是公告总数。由于一次公告可包含多组召回，两者不一定相同。

“本次推送简道云”计入本批新创建及上次响应不确定、后续查询确认已创建的记录；历史已存在而跳过的记录不计入。时间使用 UTC 存储，公告日期按 UTC+8 的本地日换算。

日志中的批次标记用于中断后的幂等恢复。不要手工删除未完成批次对应的日志标记。

## 如何获取配置

使用自己的简道云开放平台配置应用权限，记录应用、表单和控件 ID，在 `config.json` 替换全部 `REPLACE_...`。API Key 只通过 `JDY_API_KEY` 环境变量提供。

官方文档：

- [表单控件查询](https://hc.jiandaoyun.com/open/14216)
- [查询多条数据](https://hc.jiandaoyun.com/open/14220)
- [新建单条数据](https://hc.jiandaoyun.com/open/14222)

本客户端只调用 list/create，不执行更新或删除。不盲目重试 create；请求异常时先保留状态，再由下次同步查询远端确认。

控制台摘要不输出你的应用 ID、表单 ID 或真实 data_id；实际 data_id 仅保留在私有批次及你的简道云日志中。
